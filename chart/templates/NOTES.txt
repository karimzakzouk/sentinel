Post-install notes — printed after `helm install` so the user knows what to do next.
*/}}
 Sentinel {{ .Chart.AppVersion }} installed in namespace {{ .Release.Namespace }}

 Getting started:
 ══════════════

 1. Get your API token (needed to log in to the web UI):

    kubectl -n {{ .Release.Namespace }} exec deploy/{{ .Release.Name }} -- printenv SENTINEL_API_TOKEN

 2. Port-forward the web UI to your machine:

    kubectl -n {{ .Release.Namespace }} port-forward svc/{{ .Release.Name }} 8000:8000

 3. Open http://localhost:8000 in your browser and paste the token from step 1.

 4. Deploy an annotated app so Sentinel watches it:

    kubectl apply -f - <<EOF
    apiVersion: apps/v1
    kind: Deployment
    metadata:
      name: my-app
      namespace: sim
      annotations:
        sentinel.io/repo: "yourorg/your-repo"
        sentinel.io/branch: "main"
    spec:
      replicas: 1
      selector:
        matchLabels:
          app: my-app
      template:
        metadata:
          labels:
            app: my-app
          annotations:
            sentinel.io/repo: "yourorg/your-repo"
            sentinel.io/branch: "main"
        spec:
          containers:
          - name: my-app
            image: my-app:latest
    EOF

 Configuration:
 ══════════════

 - Web UI:      http://localhost:8000 (via port-forward)
 - API:         http://localhost:8000/healthz
 - Metrics:     http://localhost:8000/metrics (Prometheus format)
 - Webhook:     POST /webhook/github (for chatops + PR review)

 Chatops commands (post on any PR in a tracked repo):
   /sentinel help           — list all commands
   /sentinel status         — show investigation status
   /sentinel explain        — LLM root cause explanation
   /sentinel trace          — dump agent reasoning
   /sentinel retry-sandbox  — re-run sandbox verification

 Docs: https://github.com/karimzakzouk/sentinel
