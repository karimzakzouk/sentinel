What is Sentinel?

Sentinel plugs into any Kubernetes cluster, watches for incidents in real-time, diagnoses them with an LLM, writes fixes, tests them in a sandbox, and opens Pull Requests — all on its own.

🔴 Live Detection

Streams pod logs in real-time. Catches runtime errors (ZeroDivisionError, panic, NullPointerException) the instant they happen. Zero delay, no polling.

🧠 Agentic Investigation

Clones your repo, searches the source code with regex, reads the relevant files — same pattern as SWE-agent and OpenHands. The LLM sees the actual buggy code.

🔧 Autonomous Fixes

Writes the actual file changes, not recommendations. Builds a canary image with Kaniko, tests it in a sandbox, opens a PR with sandbox-verified label.

✅ 3-Level Verification

Every fix is tested: (1) canary pod starts, (2) endpoints return 2xx, (3) the original error is gone. No unverified fixes ship.

🛡️ Embedded Safety

5 governance rules (production namespace, high-risk service, blast radius, schema-migration block, confidence threshold). No OPA sidecar — pure Go.

📦 Zero Dependencies

One Go binary, one pod, ~28MB. SQLite replaces Postgres + Weaviate. No Kafka, no Redis, no external services. Just plug and sleep.

The agent loop (what makes it accurate)

Sentinel doesn't guess which files to look at. It does what real coding agents do:

1. Clone the repo locally (go-git, ~2 seconds)
2. Walk the file tree (filtered: no node_modules, vendor, .git)
3. LLM Round 1: "what should I search for?"
   → emits 3-8 search queries: ["DB_PASSWORD", "KeyError", "def main"]
4. Run the searches locally (Go regexp)
   → instant, no API calls, no rate limits
5. LLM Round 2: "given these results, what's the root cause?"
   → returns hypotheses + files to read
6. Read those files from disk (zero API calls)
7. Pass source to Fix Proposer → writes the patch
8. Build canary image → sandbox verify → open PR

Same pattern as SWE-agent, OpenHands, and Aider. Works for any repo, any language, any layout.

Install in 60 seconds

helm repo add sentinel https://karimzakzouk.github.io/sentinel/
helm repo update

helm install sentinel sentinel/sentinel --version 1.7.0 \
  --namespace sentinel --create-namespace \
  --set sentinel.githubToken=YOUR_GITHUB_TOKEN \
  --set sentinel.llm.apiKey=YOUR_LLM_API_KEY \

  --set 'sentinel.rbac.writeNamespaces={sim}'

Enroll your services

Annotate your Deployments so Sentinel knows what to watch:

metadata:
  annotations:
    sentinel.io/repo: myorg/my-app           # GitHub repo (required)
    sentinel.io/branch: main                  # Branch that's deployed (required)
    sentinel.io/git-commit: abc123...         # Exact commit (optional)

Once annotated, Sentinel automatically starts live-streaming the pod's logs. When an error is detected → full pipeline runs autonomously → PR opened. No manual triggers needed.

Architecture

sentinel/
├── cmd/sentinel/              # Entrypoint
├── internal/
│   ├── schemas/               # All types (Go structs)
│   ├── config/                # Env var loading + LLM provider resolution
│   ├── llm/                   # OpenAI-compatible client (net/http, no SDK)
│   ├── k8s/                   # Workload annotation lookup, pod logs, CR status
│   ├── watcher/               # CRD watcher (manual trigger)
│   ├── detection/             # Autonomous detection (live log streaming + pod status)
│   ├── repo/                  # go-git cloner + local search engine
│   ├── agents/                # 4-agent pipeline + state machine
│   │   ├── pipeline.go        #   Wires agents + handles rewinds
│   │   ├── investigator.go    #   Two-round agentic loop (clone → search → read)
│   │   ├── evidence_gatherer.go #   K8s API queries in parallel
│   │   ├── analyst.go         #   Bayes + Beta priors → root cause
│   │   └── fix_proposer.go    #   Root cause → FixProposal (LLM)
│   ├── safety/                # Embedded policy (5 if-statements, replaces OPA)
│   ├── executors/             # GitHub PRs, K8s patches, sandbox, Kaniko
│   ├── feedback/              # SQLite store (incidents + events + beta + vectors)
│   └── api/                   # HTTP API
├── chart/                     # Single-pod Helm chart
├── Dockerfile                 # Distroless static, ~28MB
├── go.mod
└── README.md
