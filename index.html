Sentinel Helm Repo

This is the Helm chart repository for Sentinel — the Autonomous AI Site Reliability Engineer.

Install

helm repo add sentinel https://karimzakzoukz.github.io/sentinel/
helm repo update
helm install sentinel sentinel/sentinel \
  -f my-values.yaml \
  --namespace sentinel --create-namespace
