Sentinel is installed as one Helm release (CRDs + controller{{ if .Values.fence.enabled }} + fence{{ end }}).

Profile: {{ .Values.profile }}
Watched namespaces: {{ join ", " (include "sentinel.watchList" . | fromJsonArray) }}

{{- if eq .Values.profile "observe" }}
Observe mode: Sentinel reads, reports and records. It changes nothing until
you set profile=full (or enable actor/lab) and add a Policy in the UI.
{{- else }}
Full profile: actor and Lab are installed. Acting still needs a SentinelPolicy
per namespace (Policies in the UI). The Fixer needs forge credentials separately.
{{- end }}

Open the console:

  kubectl -n {{ .Release.Namespace }} port-forward deploy/sentinel 8090
  # then http://localhost:8090 — sign in with a Kubernetes token

Day-2 is the UI: Settings (kill switch, detection, Slack/LLM secrets, MITM),
Policies (who may act where), Cluster (what this cluster allows).

{{- if .Values.nodeAgent.enabled }}

Node agent: on (DaemonSet tails /var/log/pods on every node).
{{- else }}

Node agent: off. Opt in with --set nodeAgent.enabled=true where nodes allow it.
{{- end }}
{{- if .Values.capture.enabled }}

Traffic capture: on.
{{- else }}

Traffic capture: off. Opt in with --set capture.enabled=true (privileged eBPF).
{{- end }}

Company install (published chart, no clone):

  helm install sentinel oci://ghcr.io/karimzakzouk/charts/sentinel \
    --namespace sentinel --create-namespace \
    --set-json 'global.watchNamespaces={{ include "sentinel.watchList" . }}' \
    --set profile={{ .Values.profile }}
